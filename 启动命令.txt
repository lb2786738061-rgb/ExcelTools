========================================================================
             Office 智能效率工具箱 - 前后端启动命令与指南
========================================================================

【一、 环境准备】
项目基于 Node.js 环境开发，运行前请确保本地已安装 Node.js (推荐 v16+ 或 v18+)。

------------------------------------------------------------------------

【二、 前端开发服务启动】

1. 打开终端/命令行 (cmd / PowerShell)，进入项目根目录：
   cd /d E:\projects\ExcelTools

2. 运行前端开发启动命令：
   npm run dev

3. 访问地址：
   启动成功后在浏览器打开：http://localhost:5173

------------------------------------------------------------------------

【三、 后端商业 API 服务启动 (支持 C# .NET / Node.js 双版本)】

1. 打开另一个新的终端/命令行窗口，进入项目根目录：
   cd /d E:\projects\ExcelTools

2. 运行 C# (.NET 8.0 / Web API) 后端启动命令 (推荐)：
   npm run server:dotnet

   或运行 Node.js 后端启动命令：
   npm run server

3. 服务端口：
   后端 HTTP API 运行在：http://localhost:5001
   (提供用户鉴权登录、VIP充值扣费、文档自动化处理日志)

4. 可选环境变量（Node / .NET 通用，未设置时使用本地开发默认值）：
   JWT_SECRET                 HMAC 签名密钥（生产环境必须更换）
   JWT_EXPIRES_SECONDS        Token 有效期，默认 604800（7 天）
   ADMIN_USERNAME / ADMIN_PASSWORD
   DEMO_USERNAME / DEMO_PASSWORD
   GUEST_TRIAL_BALANCE        未登录访客试用次数，默认 3
   ZHIPU_API_KEY              智能助手智谱密钥（也可用 appsettings.json 的 Zhipu:ApiKey）
                              模型：glm-4.6v
   说明：仅在首次生成 server/data/db.json 时写入管理员与演示账号；已有库文件不会覆盖。
   未登录会签发独立访客 Token，不再占用 testuser 的 VIP 额度。

------------------------------------------------------------------------

【四、 快速一键命令说明】

- 启动前端开发服务器：
  npm run dev

- 启动后端 Node 服务：
  npm run server

- 项目生产环境打包构建：
  npm run build
